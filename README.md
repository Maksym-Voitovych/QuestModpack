# All in One Adventure 2.0 — AIA2

**0.4.25-alpha — verified CDG panel production.**
Minecraft1.21.1 NeoForge / FTB Quests2101.1.36 / KubeJS2101.7.2 / Rhino85.
The full0.5 update remains in progress.

A new optional epoch12 objective follows the exact Lines profile course. It
requires a native team production receipt and four panel samples. The existing
Basin completion hook records only successful actual application. A new codec
check rejects same-ID recipes with changed ingredients, mold, output or chance;
a separate live check rejects a missing or changed public MoldType.

**3403quests/140chapters/6groups,627recipes,3139item rewards,390items/models/PNGs,
48epochs and96manufactured keys.** All3402old non-coordinate quest payloads,
old16mechanic rules and their order remain unchanged. The new17thrule uses
schema1 receipts. No new optional Mixin selector, item, texture or recipe.

The companion builds with JDK21/NeoForge. Source contracts, modeled-host native
regressions, migration checks and minimal-server tests have separate scopes.
The original CDG/Create binaries, FTB UI, full client, JEI, Survival and TPS have
not been tested here. Current results: [checkpoint](docs/AIA2_0.4.25_CHECKPOINT.uk.md).

Stop Minecraft, extract separately, then run
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`.
Run again without the flag and restart both sides fully. Changed files and the
old owned JAR are backed up; worlds and player/team progress are never edited.
