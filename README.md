# All in One Adventure 2.0 — AIA2

**0.4.12-alpha** targets Minecraft 1.21.1 NeoForge, FTB Quests 2101.1.36, KubeJS 2101.7.2 and Rhino build85. The full 0.5 update remains unfinished.

**48 epochs, 96 manufactured keys, 3346 quests in 140 chapters, 623 native custom recipes and 390 items/models/PNG.** Added 16 Forbidden Arcanus goals and six native ritual criteria. All 3330 previous task/reward/dependency payloads and 623 recipe entries are retained; one missing Forge icon is repaired. New recipes/items/textures: 0.

Forbidden's 24-stage scoped core teaches formation, essence carriers, actual rituals/upgrades and Clibano preparation. Three optional hooks validate the actual forge owner, current definition, physical inputs/enhancers, payment and result. Changed/removed paid rituals pause while retaining their NBT; legacy operations without proof remain paused. `/aia2forge status x y z` diagnoses them; operator-only `cancel` keeps a bounded backup and physical inputs, without essence refund or output.

212 Python tests, 55 Node tests, 5237 Java assertions and 111 minimal Minecraft assertions in two JVM passed. The 297 new optional-host assertions are modeled. Full Forbidden weaving, JEI/UI, Survival and TPS are NOT RUN. Internal Clibano production ownership and transitive registry effects remain open; native ritual criteria precede final output acceptance.
