# All in One Adventure 2.0 — AIA2

**0.4.18-alpha — verified NASA manufacturing checkpoint.** Minecraft 1.21.1
NeoForge, FTB Quests 2101.1.36, KubeJS 2101.7.2 / Rhino85. Full 0.5 remains
in progress; the complete client has not been tested.

Four new optional Ad Astra quests distinguish rocket possession from actual
NASA production. The owner team's receipt requires accepted world output and
fourteen exact native input debits, with current recipe, tag, team and stage
checks. `/give` alone cannot provide it. This is evidence of manufacture;
mid-operation failures do not roll back native output or payment.

**48 epochs, 96 manufactured keys, 3375 quests / 140 chapters, 627 recipes,
3111 item rewards, 390 items/models/PNGs.** All 3371 earlier quest payloads
and 627 recipes are preserved. Four new small material rewards; no new recipes,
items or textures. Five old quest coordinates move; layout retains 1154 crossings
with no structural warnings.

The installer checks compiled NASA method/invocation contracts against an
available Ad Astra JAR before backup/write. The ProjectE tablet hotfix and
its preflight remain. Original installed optional binaries are not supplied;
source-shaped Sponge tests and the minimal server do not certify full-pack
weaving, JEI, Survival or TPS.

Stop Minecraft, extract the package and run
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`, then omit
the flag. Originals and the old owned JAR are backed up; worlds, player progress
and foreign content are preserved. Restart both sides completely.
