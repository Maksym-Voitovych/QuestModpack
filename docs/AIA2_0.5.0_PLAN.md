Базова версія: **0.4.0-alpha**, коміт `90ab63f6a32794edb9d97b0ee61b976cf69b4585`.
База: 48 епох, 96 виробничих ключів, Machine Guard API 4, 2784 квести,
130 глав, 569 нативних рецептів і 48 формул фінального гравіювання.
Версію 0.5.0-alpha можна оголосити лише після завершення перевіреного обсягу;
проміжні робочі зміни мають власні коміти та чесний статус незавершеної роботи.

Поточний checkpoint: **0.4.22-alpha — збереження журналу ключів і точні віхи37/38**.
Уточнено лише title/description дванадцяти старих віх: показати предмет або
здати його з витратою. Tasks/IDs/rewards/deps/coords збережені. Key journal
schema1 захищений від empty replacement після IO/load failure, без фабрикації
proofs чи нормалізації aliases. Installer перевіряє compiled capability1.
Чотири required NASA та шість optional station goals не змінено. Стан фінальних
QA/доставки й Git — у PROGRESS. Наступний змістовний блок —34partial карти й
решта required48ліній; не повторювати завершені NASA/станції/назви/journal.
Original optional binaries/client/JEI/Survival/TPS BLOCKED/NOT_RUN. Повний0.5 не готовий.

Наступна конкретна дія після доставки0.4.22: scoped course Create Crafts &

## Правило відновлення

На команду «Продовжуй» спочатку прочитати цей файл і
`docs/AIA2_0.5.0_PROGRESS.md`, виконати `git status`, переглянути останні
коміти. Продовжувати першу незавершену дію, зважаючи на власників файлів.
Не повторювати завершені зміни та не скидати користувацький прогрес.

## Незмінні вимоги

- Зберігати ID всіх старих квестів, завдань, нагород, предметів і 48 тем епох.
- Не видаляти світи, журнали прогресу, сторонні моди чи невідомі квести.
- Резервувати змінювані оригінали до встановлення; підтримувати dry-run і відкат.
- Обидва ключі потребують справжнього виробництва, обидвох гілок і FTB-фіналу.
- Жодних випадкових вибірок предметів, фіктивних API чи неперевірених serializer.
- Розрізняти статичні перевірки, справжній Rhino, мінімальний Minecraft-сервер
  та повний інстанс із усіма модами. Не прирівнювати їхні результати.
- Після логічного блоку оновлювати PROGRESS, виконувати релевантні перевірки,
  створювати коміт і push без force. Особисті дані й backup не комітити.

## Постійні артефакти

- `content/research/`: структуровані карти модів, використані джерела й межі доказів.
- `content/quests/`: авторські квести; старі каталоги та логічні ID зберігаються.
- `content/recipes/`: перевірені зміни рецептів із джерелами та причинами.
- `tools/`: генератори, аудит і валідатори; `tests/`: позитивні та негативні регресії.
- `implementation/`: кількості, порівняння, результати тестів і відомі обмеження.
- `docs/AIA2_0.5.0_PROGRESS.md`: авторитетний стан між сесіями.
