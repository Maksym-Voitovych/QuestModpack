# Ребаланс і аудит обходів прогресії

Опрацьовано 61 контрольну ціль/сімейство. Усі явні target та додані/замінені item IDs є в `registries/item.json`. Це проєкт рецептурних змін, не встановлені KubeJS-скрипти. Native serializers, компоненти й стадійні hooks потребують перевірки в актуальній збірці.

## Критичні результати

- Game Stages зберігає стан. Реальну заборону крафту, використання, видобутку, вимірів і роботи машин забезпечують окремі підтверджені hooks/аддони; приховування JEI недостатньо.
- `mods.json` містить 333 записи, жодного stage-named mod ID. Повідомлене пізніше встановлення Game Stages треба звірити з новим логом/експортом.
- Є 5 старих `kubejs:aia2_v071/v072/v073` proof-рецептів, але нуль зареєстрованих `kubejs:*` предметів. Не використовувати старі proofs як валідні компоненти без startup/server scripts.
- **Доведений обхід:** `create_mekanism_improvements:pollonium_pellet` створює polonium через Create; `:antimatter_pellet` створює antimatter без SPS. Вилучити саме ці shortcut-рецепти, зберегти native Mekanism і gate вихідного ресурсу в усіх інших модах (33/39).
- Create Ultimate Factory може автоматизувати diamond/blaze rods/wither skulls/netherite scrap/chorus. Власна стадія кожного output обов’язкова; namespace-gate не захищає від суміжних модів.
- Native Avaritia: `avaritia:shaped_table` + tier; Extreme Table крафтиться на 7×7/tier3, Neutron Collector на 9×9/tier4. Не підміняти 3×3 та не викидати драбину столів. Infinity Catalyst має type `avaritia:infinity_catalyst`, implicit output і **bedrock** в original inputs; пропозиція нижче прибирає цей недосяжний компонент, зберігаючи native процес.
- `ironjetpacks:jetpack` і `ironjetpacks:cell` залежать від tier/components. До отримання повних stack/config templates конкретний рецепт лишається заблокованим; raw item ID не визначає tier. Виробничий native рецепт Eternal Stella не наданий; наявний лише smithing застосування — 3×3 рецепт не вигадано.
- `rftoolsbuilder:shape_card_quarry` має `mcjtylib:copy_components`; region/shape data треба зберігати. Single Chunk Loader — 1 basic→9single; Powah Nitro — output4. Batch outputs збережені.
- `blocks/*` loot є здебільшого selfdrop вже створеного блока, а не природна знахідка OP-машини. Природні chest/entity/trade джерела перевіряються окремо.

## Правила формул

Для звичайних shaped-рецептів нижче наведено повний набір витрат і 3×3 pattern `TMT / MPM / TMT`. Для native процесів таблиця містить **тільки точні заміни/добавки**: решта витрат і всі constraints збережені в повній source recipe копії `preserved_source_recipe` у JSON. Там же записано координати змін, чинні tier/energy/activation/conditions. Native специфікація не є готовим runnable serializer. Жоден ключ епохи не входить у звичайний рецепт.

## EMC, джерела та перевірки

1. EMC — whitelist для вже відкритих базових витратних матеріалів. Ключі, proofs, critical alloys, boss kill evidence і ресурси майбутніх епох не отримують EMC. `forbidden_arcanus_emc`, AppliedE та collector/relay-петлі перевіряються разом.
2. При заміні manufacturing не видаляти всі `source_recipe_ids` гуртом: block/nugget декомпозиції, config wipe та component-copy конверсії лишаються на тій самій стадії і не мають нової одноразової плати.
3. Насіння, orechid/miner/laser outputs, mob predictions, casting/uncrafting/recycling, лут і торгівля мають власний output gate. Дорожчий altar або quarry не доводить захищеність кожного ресурсу.
4. Виміряти реальні FE/t, drops/min і TPS: позначки Nitro/Quantum/Ultimate різних модів непорівнянні без актуального config. Ліміти чанків/команд і офлайн-генерації важливіші одноразової ціни.
5. Негативні тести: чужі предмети й блоки, заблоковані виміри, AE autocrafting, hopper/fake player, relog, зміна команди, втрата ключа, старі component stacks, output іншого namespace.

Машинозчитуваний документ: `op-candidates.json` (61 запис; source IDs/types, template copies, точні заміни, constraints, batches, explicit blockers).

## Узгодження фінальних стадій

- Condenser Mk1 —45; collectors Mk1/Mk2/Mk3 та native relays —47, лише common-material EMC whitelist. Infinity й progression resources ніколи не одержують EMC.
- Infinity Pickaxe та creative control/generators — після завершення48. **Infinity Chestplate дозволено48 до фінального ключа** як mastery, а не blanket post-final для всієї Avaritia. Усі обов’язкові боси завершені42; додаткового обов’язкового боса48 немає.
- Foliot miner —28, бо native ритуал уже споживає iesnium pickaxe. AdvancedAE Quantum Crafter —39.

## Перевірка недосяжних входів

Перевірено всі збережені native templates і явні нові витрати на bedrock, barrier, end portal frame, command blocks, reinforced deepslate, light, structure/jigsaw/void/debug блоки та creative-named inputs. Після застосування проєктних overrides невирішених збігів немає.

- Extreme Crafting Table: усі **4×** reinforced deepslate замінено на **4× `allthemodium:unobtainium_block`** (доступ44); єдине dragon egg — на **1× `draconicevolution:dragon_heart`** з повторюваної перемоги. Збережено native7×7/tier3 і драбину попередніх столів.
- Infinity Catalyst: bedrock прибрано зі списку native ingredients; процес `avaritia:infinity_catalyst` з implicit output збережено.

Original `preserved_source_recipe` залишається незмінним доказом експорту; чинні проєктні зміни записано у `ingredient_changes`. Відсутність заборонених ID не замінює runtime перевірку рецептів і джерел отримання.
