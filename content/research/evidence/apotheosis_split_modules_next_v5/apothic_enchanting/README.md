# Apothic Enchanting [![](http://cf.way2muchnoise.eu/1063926.svg)](https://www.curseforge.com/minecraft/mc-mods/apothic-enchanting) [![](http://cf.way2muchnoise.eu/versions/1063926.svg)](https://www.curseforge.com/minecraft/mc-mods/apothic-enchanting)

Apothic Enchanting is a NeoForge mod that provides a full overhaul to Minecraft's enchanting system, as well as new enchantments and utilities to further improve the experience.

See the [CurseForge Page](https://www.curseforge.com/minecraft/mc-mods/apothic-enchanting) for the full description.
