# AIA2: кодовий пакет 0.2.1-alpha

У кореневих `kubejs/`, `config/` і `mods/` — ігрові JS/JSON/SNBT і власний NeoForge-мод AIA2 Machine Guard. Версія 0.2 додає контроль стандартних тіків машин, перевірки ванільного крафту до списання ресурсів та нативні докази роботи Create. **Повна збірка з усіма вашими модами ще не запускалася; перевірка кожного внутрішнього рецепта залишається незавершеною.**

Файли встановлюються з Git через `install_runtime.py` з резервними копіями. Встановлення: [INSTALL.uk.txt](INSTALL.uk.txt). Межі покриття: [KNOWN_LIMITATIONS.uk.txt](KNOWN_LIMITATIONS.uk.txt). Вихідний код і перевірки нативного моду: [companion/README.uk.md](../companion/README.uk.md).

## Зміни 0.2

- Повна карта `blockGates` на 16 003 зареєстровані блоки. Вона охоплює 1 738 блоків без однойменних предметів, зокрема перетворені частини машин.
- Машини зі стадією від 2 потребують власника — FTB-команди. Перед стандартним `BlockEntityTicker` мод перевіряє епоху цієї команди; заборона зупиняє й кешоване виконання всередині цього тіку. Стан власника зберігається в NBT.
- Власник задається після дозволеного встановлення або першої дозволеної взаємодії з безхазяйною машиною. Відвідувач не переписує наявного власника.
- Звичайний крафт 2×2 і 3×3 перевіряє епоху результату до взяття й витрати інгредієнтів. Окремо перевіряються shift-click та ванільний Crafter, включно із запланованим тіком блока. Сам Crafter відкривається в епосі 10.
- Удари заблокованою зброєю скасовуються до нанесення шкоди.
- E02_M2 потребує запуску водяного колеса; E04_M1 — пресування; E04_M2 — помелу ТА змішування. Це чотири справжні нативні досягнення Create, додані до предметних умов.
- Обов'язковий режим адаптера: без готового Java-моду `/aia2 key` відмовляє до витрати матеріалів. Помилка журналу також закриває доступ, не скидаючи прогрес.
- Перед кожним захищеним крафтом адаптер читає поточну FTB-команду через публічний API. Зміна команди не залишає доступу зі старого кешу; помилка визначення команди закриває операцію.

## Решта пакета

48 ключів, 48 глав FTB Quests, 336 обов'язкових та 96 додаткових квестів; 91 нативний рецепт із переплетенням магії й техніки. ProjectE після кожного remap зберігає лише 14 звичайних EMC-матеріалів. Ключі створюються серверною транзакцією `/aia2 key` біля верстака: спочатку перевіряються шість віх, потім списуються матеріали. Вони потрібні лише для наступного ключа і фіналу глави.

KubeJS Create використовує перевірений `event.recipes.create.mixing`; складні інші рецепти використовують `event.custom(native_json)` зі збереженням нативної структури. Вигаданих методів аддонів і непрацюючого `recipe.stage()` немає.

## Перевірка

```sh
node --test tests/*.test.js
python3 -m pip install -r tools/test-requirements.txt
python3 tools/validate_game_pack.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
JAVA_HOME=/path/to/jdk-21 python3 companion/test_policy.py
cd companion
./gradlew build
```

JavaScript-тести перевіряють фактичні скрипти через модель Java API; це не запуск усіх модів. NBT-парсер незалежно розбирає всі 48 глав. Окремий тест інсталятора перевіряє dry-run, резервну копію, збереження обов'язкового режиму та повторне встановлення без змін. Фактичні результати нативного збирання й smoke-test наведені в `companion/verification-report.json`; загальні результати — у `validation-report.json`.

## Межа нового захисту

Заблокована машина не тікає, але вже дозволена рання машина ще може виконати пізніший рецепт, якщо нативний мод дає їй відповідні входи. Для цього потрібні наступні адаптери конкретних процесів. Зупинка стандартного тіку також не охоплює всі сутності, рухомі конструкції, глобальні обробники та capability IO. Мод не прикидається завершеним RecipeStages для всіх 293 модів.

## Інтеграція квестів зі стадіями

Усі шість віх кожної епохи мають додатковий advancement task `aia2:stages/eNN`, побудований на нативному `gamestages:has_stage`. Умова містить `stage: aia2_epoch_NN`. Фінал автоматично виконує `aia2 sync` від імені отримувача; окремих прав оператора не потрібно. Авторитетом залишається командний журнал. Крафт ключа додатково перевіряє живу стадію через `GameStageHelper.hasStage()`. Перевірено вихідний код Reborn15.1.1; фактичний JAR користувача тут не запускався.
