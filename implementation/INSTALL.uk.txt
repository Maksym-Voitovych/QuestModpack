AIA2 — кодовий пакет 0.2.1-alpha
Minecraft 1.21.1 / NeoForge 21.1.264; KubeJS 2101.7.2-build.377;
Game Stages Reborn (API звірено з 15.1.1); FTB Quests 2101.1.36; ProjectE PE1.1.0; моди вашої збірки.

Пакет містить JS/JSON/SNBT і скомпільований власний мод:
  mods/aia2-machine-guard-0.2.0-alpha.jar
Джерела та native build/smoke-test: companion/verification-report.json.
Повна ваша збірка тут ще не запускалася. KNOWN_LIMITATIONS.uk.txt описує,
які рецепти й механіки ще потребують окремих адаптерів.

ВСТАНОВЛЕННЯ
1. Закрийте клієнт і сервер. Для першого запуску використайте копію інстансу
   й окремий тестовий світ; збережіть резервну копію наявного світу.
2. Клонуйте репозиторій та відкрийте гілку з опублікованими змінами:
     git clone https://github.com/Maksym-Voitovych/QuestModpack.git
     cd QuestModpack
   Поруч із install_runtime.py розміщені kubejs/, config/ та mods/.
   Для оновлення вже клонованої копії отримайте актуальні зміни своєї гілки
   через Git; не стирайте власні локальні зміни.
3. Python 3.9 або новіший:
     python install_runtime.py "C:/шлях/до/інстансу" --dry-run
     python install_runtime.py "C:/шлях/до/інстансу"
   На Linux зазвичай python3. Папка інстансу має містити mods/.
4. Встановіть ті самі файли на клієнт і сервер. Кореневі mods/* — у mods/,
   kubejs/* — у kubejs/, config/* — у config/ відповідного інстансу.
   Власний мод AIA2 обов'язковий. Інсталятор не завантажує решту модів.
5. Попередні файли зберігаються в aia2-backups/<час>/original/.
   Наявний FTB data.snbt зберігається. ProjectE custom_emc.json зливається
   за ID. Уже налаштований machineGuard.mode=required не знижується.
6. Потрібен повний перезапуск; /reload не реєструє нові предмети чи JAR.
   При переході з 0.1 alpha потрібно оновити всі файли, включно з config.
   Не додавайте попередні ручні epoch_keys.js/epochs_01_06.js поруч із
   канонічними скриптами в kubejs/*_scripts/aia2/: це дублює ті самі записи.

ЯК ГРАТИ
/aia2 — довідка.
/aia2 status — епоха FTB-команди та стан Machine Guard.
/aia2 key — створити поточний ключ біля верстака.
/aia2 sync — синхронізувати власні advancement і Game Stages.
/aia2 recover — платно відновити останній законний ключ без нових епох.
Для відновлення потрібні ті самі T/M/R/S-матеріали; замість попереднього
ключа — один запасний верстак. Це не замінює доказів квестового прогресу.

Виконайте всі шість обов'язкових завдань. У завданнях зазначено, які
матеріали витрачаються. Чотири докази Create додатково потребують роботи
колеса/преса/жорна/мішалки: поставте машини власноруч і будьте онлайн.
Усі вказані tasks обов'язкові. Предметна здача не замінює process tasks.
Зберіть дев'ять складових ключа в головному інвентарі, станьте біля
звичайного верстака та виконайте /aia2 key. Перевірка відбувається ДО
списання. Фінальний квест не забирає ключ; його споживає лише наступний ключ.

Ключі не мають звичайних shaped-рецептів. Вартість видно у FTB Quests і JEI.
Не використовується recipe.stage(), який не працює у базовому KubeJS 2101.

МАШИНИ
У нових staged-машин власником стає FTB-команда гравця, який їх поставив.
Безхазяйна машина зі стадією від 2 зупинена; після відкриття потрібної
епохи натисніть на неї правою кнопкою, щоб призначити власника.
Власник зберігається в NBT; інша команда не переписує його взаємодією.
Звичайні cached-процеси заблокованої машини зупиняються до її тіку.
Ванільний Crafter відкривається в епосі 10 й окремо перевіряє епоху результату.
Це ще не фільтр кожного рецепта всередині всіх уже дозволених ранніх машин.

Пакет використовує обов'язковий режим Machine Guard. Якщо JAR не встановлено,
міксини не застосувалися або журнал не завантажився, ключі не створюються.
Перевірте mods/, kubejs/logs/startup.log, server.log і logs/latest.log.
Зміна режиму на optional вимкне цю гарантію і не є виправленням помилки.

ПЕРША ПЕРЕВІРКА У ГРІ
1. У логах немає script/mixin errors, /aia2 status показує активний адаптер.
2. Ключі зареєстровані та мають JEI Information.
3. Без шести віх крафт ключа відмовляє без витрати матеріалів.
4. У тестового раннього гравця недоступний результат звичайного крафту
   не забирається ні звичайним кліком, ні shift-click; інгредієнти зберігаються.
5. Установлена/завантажена staged-машина без власника зупинена до claim.
   Чужа команда не змінює власника. Перезапуск зберігає це поле.
6. Crafter із недоступним результатом не видає його і не витрачає входи.
7. Перевірте ключ після виконання шести віх і збереження прогресу після restart.
8. Перевірте синхронізацію команди, заборонений вимір та melee-зброю.
9. ProjectE має EMC лише для 14 whitelist-матеріалів.

Повний перелік залишкових меж — KNOWN_LIMITATIONS.uk.txt.

КВЕСТОВІ СТАДІЇ
Кожна обов’язкова віха потребує нативного Game Stages advancement.
Фінальний квест автоматично виконує aia2 sync від імені отримувача.
Використовуються aia2_epoch_01…48 та aia2_done_01…48; @p не застосовується.
Якщо стадія відсутня, /aia2 key відмовляє до витрати ресурсів.
