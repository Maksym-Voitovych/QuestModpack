AIA2 0.3.0-alpha — встановлення

1. Закрийте гру та сервер. Збережіть окрему копію свого інстансу/світу.
2. Завантажте main з GitHub або розпакуйте AIA2-runtime-0.3.0-alpha.zip.
3. У папці з install_runtime.py:
   python -m pip install nbtlib==2.0.4
   python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run
4. Перевірте список і застосуйте:
   python install_runtime.py "C:\CurseForge\AllInOneAdventure2"
   H:\CurseForge\Instances\All in One Adventure 2.0 — Junction на той самий
   інстанс; повторно через H встановлювати не потрібно.
5. Інсталятор резервує всі змінювані оригінали ДО першої заміни, зливає
   групи та невідомі квести, зберігає data.snbt/світи/прогрес. Старий власний
   aia2-machine-guard-*.jar переноситься в backup перед заміною. Сторонні
   моди не видаляються. Шлях backup виводиться після встановлення.
6. Для клієнта й окремого сервера встановіть однакові runtime-файли.
   Повністю перезапустіть обидва: /reload не додає startup-реєстрації.
7. Не копіюйте додатково старі ручні epoch_keys.js/epochs_01_06.js:
   дублювання реєстрацій або рецептів викликає конфлікт. Власні сторонні
   скрипти автоматично не видаляються; перед міграцією перевірте їх.
8. /aia2 status; /aia2 sync. Новий гравець починає з епохи1. Раніше
   законно завершені епохи залишаються. Для нового ключа потрібні всі
   віхи, обов’язкові модові гілки, випробування та компоненти; /aia2 key
   виконується біля звичайного верстака. Втрата останнього ключа:
   /aia2 recover, без відкриття наступної епохи.
9. Старі/імпортовані машини без власника натисніть ПКМ дозволеним гравцем,
   щоб призначити команду. Машину з власником відвідувач не перепризначає.
   Належність і прогрес мають зберегтися після перезапуску.

Це alpha. Перевірте сценарії з KNOWN_LIMITATIONS.uk.txt до проходження
на основному світі. Інсталятор не містить і не встановлює решту модів.
Повна інструкція й команди тестування: README.uk.md.
