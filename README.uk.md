# All in One Adventure 2.0 — AIA2

**0.4.22-alpha — збереження журналу ключів і точні космічні віхи.**
Minecraft1.21.1 NeoForge / FTB Quests2101.1.36 / KubeJS2101.7.2 / Rhino85.
Повний0.5 ще в роботі.

Журнал виробництва ключів тепер зберігає наявний нечитабельний файл замість
його заміни порожньою історією. Сувора перевірка NBT, узгоджені межі читання
та запису й перевірка matching JAR захищають усі96доказів. Старі неканонічні
написання залишаються буквально збереженими й не дають нових дозволів.

**3381квест/140глав,627рецептів,3117предметних нагород,390предметів/моделей/PNG,
48епох і96виробничих ключів.** Типи, кількості, ID й payloads завдань та нагород
не замінюються. Змінено лише назви й описи12старих віх епох37–38: показати
предмет або здати його з витратою. Залежності, нагороди, координати й прогрес
збережені. Чотири required NASA-цілі, шість optional station goals та правила
оплачених переходів залишилися незмінними.

API4, ProjectE hotfix, mechanic/station guards збережені. Автоматичні,
модельовані та мінімальні серверні тести мають окремі межі. Оригінальні
optional binaries, повний клієнт, JEI, Survival і TPS ще не перевірені.

Зупиніть гру, розпакуйте пакет окремо й виконайте
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`.
Після перевірки повторіть без прапорця й повністю перезапустіть обидві сторони.
Інсталятор резервує змінювані файли та старий власний JAR; світи й прогрес
гравців не редагуються.
