# All in One Adventure 2.0 — AIA2

**0.4.25-alpha — доказ виробництва панелей CDG.**
Minecraft 1.21.1 NeoForge / FTB Quests 2101.1.36 / KubeJS 2101.7.2 / Rhino85.
Повний 0.5 ще в роботі.

Новий побічний квест епохи12 продовжує курс профілю Lines. Для завершення
потрібні серверний доказ виробництва поточної команди та чотири панелі.
Чинний Basin hook спостерігає успішне фактичне виконання. Нова перевірка
codec відхиляє рецепт із тим самим ID, якщо змінено сировину, форму, результат
або ймовірність; окремо звіряється чинний публічний MoldType.

**3403 квести / 140 глав / 6 груп, 627 рецептів, 3139 предметних нагород,
390 предметів/моделей/PNG, 48 епох і 96 виробничих ключів.** Усі 3402 старі
payloads без координат та попередні16 правил доказів із порядком збережено.
Нове17-те правило використовує наявний schema1 журнал. Нових optional Mixin
selectors, предметів, текстур або рецептів немає.

JAR зібрано з JDK21/NeoForge. Статичні контракти, modeled-host регресії,
перевірки міграції та мінімального сервера мають окремі межі доказів.
Оригінальні CDG/Create binaries, FTB UI, повний клієнт, JEI, Survival і TPS
тут не перевірено. Актуальні результати: [checkpoint](docs/AIA2_0.4.25_CHECKPOINT.uk.md).

Зупиніть гру, розпакуйте пакет окремо й виконайте
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`.
Після перевірки повторіть без прапорця й повністю перезапустіть обидві сторони.
Інсталятор резервує змінені файли/старий JAR і не редагує світи чи прогрес.
