# All in One Adventure 2.0 — AIA2

**0.4.20-alpha — збережувані докази будівництва станцій Ad Astra.**
Minecraft1.21.1 NeoForge / FTB Quests2101.1.36 / KubeJS2101.7.2 / Rhino85.
Повний0.5 ще в роботі.

Додано шість необов’язкових цілей орбітального будівництва. Сервер перевіряє
точну оплату, прийняту й збережену структуру, рівно один новий нативний запис
станції, нормальне завершення packet та перебування того самого будівничого
на потрібній орбіті в незмінній поточній команді. Стара станція, телепортація
або предмети з /give не створюють доказ. Після пізньої помилки виконані
нативні дії залишаються; refund/rollback не вигадуються.

**48епох,96виробничих ключів,3381квест/140глав,627рецептів,3117предметних
нагород,390предметів/моделей/PNG.** Усі3375попередніх квестів і627рецептів
збережені. Нові шість доказів мають окремий командний журнал
`aia2_stations_v1`; старі15mechanic rules, NASA proofs, ProjectE hotfix
і Machine Guard API4 не замінюються. Пошкоджений журнал не перезаписується;
нове будівництво відхиляється до оплати з повідомленням про неготовність.

Зупиніть гру, розпакуйте пакет в окрему папку. Виконайте
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`, потім
ту саму команду без прапорця. Змінювані оригінали й старий власний JAR
резервуються. Повністю перезапустіть клієнт і сервер. Старі станції не
мігруються у докази нового виготовлення; старий FTB-прогрес не скидається.

Автоматичні, модельні та мінімальні серверні перевірки мають окремі звіти.
Оригінальні optional binaries, повний клієнт, JEI, Survival і TPS не перевірені.
