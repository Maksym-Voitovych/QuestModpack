# All in One Adventure 2.0 — прогресія 48 епох

Репозиторій містить ігрові KubeJS-скрипти, 48 глав FTB Quests та власний NeoForge-адаптер **AIA2 Machine Guard 0.2.0-alpha**. Файли встановлення лежать безпосередньо в `kubejs/`, `config/` і `mods/`.

**Повна збірка з усіма модами ще не перевірена в Minecraft.** Адаптер блокує недоступні машини та ванільний крафт; пізні рецепти всередині вже дозволених ранніх машин потребують подальших адаптерів. Докладне покриття: [KNOWN_LIMITATIONS.uk.txt](implementation/KNOWN_LIMITATIONS.uk.txt).

## Встановлення з Git

```sh
git clone https://github.com/Maksym-Voitovych/QuestModpack.git
cd QuestModpack
python3 install_runtime.py "/path/to/minecraft-instance" --dry-run
python3 install_runtime.py "/path/to/minecraft-instance"
```

Після клонування виберіть гілку з опублікованими змінами, якщо вони розміщені не в гілці за замовчуванням. У Windows замість `python3` зазвичай використовується `python`. Інстанс має вже містити встановлені моди збірки та папку `mods/`.

Інсталятор переносить ігрові файли з кореневих `kubejs/`, `config/`, `mods/`, створює резервні копії змінених файлів і зберігає наявні налаштування FTB Quests. Встановіть їх на клієнт і сервер, потім повністю перезапустіть гру. Не копіюйте додатково попередні ручні варіанти тих самих скриптів: повторна реєстрація ключів спричинить помилку.

Покрокова інструкція: [INSTALL.uk.txt](implementation/INSTALL.uk.txt).

## Що реалізовано

- 48 предметів ключів; ключ попередньої епохи споживає лише наступний ключ.
- Нативні умови Game Stages Reborn у всіх 288 віхах і 48 автоматичних нагород синхронізації без `@p`.
- 48 глав FTB Quests: 336 обов'язкових та 96 додаткових квестів.
- 91 нативний рецепт, конкретні видалення альтернатив і переплетення магії з технікою.
- Командна транзакція `/aia2 key`: перевірка шести обов'язкових віх до витрати інгредієнтів, збереження прогресу та синхронізація Game Stages.
- Контроль встановлення/використання блоків, зброї й переходів у виміри; окрема карта 16 003 блоків.
- Власник машини — FTB-команда; перед стандартним block-entity tick перевіряється її епоха.
- Перевірка ванільного крафту 2×2/3×3, shift-click і Crafter до витрати інгредієнтів.
- Чотири нативні докази Create: запуск водяного колеса, пресування, помел та змішування.
- ProjectE: остаточний whitelist EMC для 14 звичайних матеріалів.

Скомпільований [AIA2 Machine Guard](mods/aia2-machine-guard-0.2.0-alpha.jar) обов'язковий для поточного режиму. Його [вихідний код](companion/) також збережено в репозиторії.

## Структура

| Шлях | Вміст |
|---|---|
| `kubejs/startup_scripts/aia2/` | Реєстрація 48 ключів |
| `kubejs/server_scripts/aia2/` | Рецепти, прогресія, доступ, Machine Guard, EMC |
| `kubejs/client_scripts/aia2/` | Інформація JEI та tooltips |
| `kubejs/config/` | Повні нативні рецепти та правила доступу |
| `config/ftbquests/quests/chapters/` | 48 готових SNBT-глав |
| `mods/` | Власний скомпільований AIA2 Machine Guard |
| `companion/` | Java-код адаптера та Gradle Wrapper |
| `tools/`, `tests/` | Генерація й перевірки |
| `design/` | Детальний дизайн 48 епох, моди й ребаланс |

## Перевірки

Пройдено 23 JavaScript-тест, тест інсталятора та 128 Java assertions. Усі 48 глав розібрано незалежним SNBT-парсером. Мінімальний сервер NeoForge 21.1.264 запустився та підтвердив застосування міксинів до п'яти цільових класів. Це не тест повного інстансу чи всіх ігрових процесів.

Команди перевірки й стан реалізації: [implementation/README.uk.md](implementation/README.uk.md). Нативне збирання та smoke-test: [verification-report.json](companion/verification-report.json).
