# All in One Adventure 2.0 — AIA2

**0.4.18-alpha — підтверджене виробництво NASA.** Повний реліз 0.5 ще в роботі.
Minecraft 1.21.1 NeoForge, FTB Quests 2101.1.36, KubeJS 2101.7.2 / Rhino85.

Додано чотири optional-квести виготовлення ракет T1–T4. Крім наявності ракети,
потрібен серверний запис команди власника столу: світ прийняв результат,
а 14 початкових слотів оплатили рівно по одній одиниці. Поточні рецепт,
теги, компоненти, команда й стадія перевіряються протягом виклику. `/give`
не дає виробничого доказу. Адаптер не повертає вже витрачені нативним кодом
ресурси й не відкочує його ефекти при помилці посеред операції.

**48 епох, 96 виробничих ключів, 3375 квестів / 140 глав, 627 рецептів,
3111 предметних нагород, 390 предметів/моделей/PNG.** Збережено всі 3371
попередні квестові payloads, залежності, завдання, нагороди та 627 рецептів.
Нових рецептів, предметів і текстур немає; додано чотири невеликі тематичні
нагороди. Перемістилися п'ять старих координат; 1154 перетини, нуль структурних
попереджень layout.

Інсталятор перевіряє compiled NASA method/INVOKE contracts наявного Ad Astra
JAR до backup/write. ProjectE Tablet hotfix та його preflight збережені.
Оригінальні встановлені optional binaries у хмарі відсутні. Модельні тести,
Sponge на source-shaped класах та мінімальний Minecraft-сервер не замінюють
повний клієнт, JEI, Survival і TPS; ці перевірки ще не проводилися.

Зупиніть Minecraft, розпакуйте пакет в окрему папку. Виконайте
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`, потім
ту саму команду без прапорця. Оригінали й старий власний JAR резервуються;
світи, прогрес і сторонні файли зберігаються. Повністю перезапустіть обидві сторони.
