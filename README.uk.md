# All in One Adventure 2.0 — AIA2

**0.4.21-alpha — сумісна обов’язкова NASA-прогресія епох37–38.**
Minecraft1.21.1 NeoForge / FTB Quests2101.1.36 / KubeJS2101.7.2 / Rhino85.
Повний0.5 ще в роботі.

Чотири наявні NASA-цілі стали обов’язковими: T1+T2 для технологічного ключа37,
T3+T4 для ключа38. До їхнього обов’язкового маршруту входять17підготовчих цілей.
Java перевіряє справжні командні receipts перед виготовленням нового ключа,
скрипт — перед оплатою нового переходу. Старі прапорці FTB або key receipts
не підміняють NASA-докази. Усі шість станційних цілей залишилися optional.

**3381квест/140глав,627рецептів,3117предметних нагород,390предметів/моделей/PNG,
48епох і96виробничих ключів.** Типи, кількості, ID й payloads завдань та нагород
не замінюються. Чотири зміни залежностей описані явно; інші46епох незмінні.
Завершений прогрес і старі оплачені pending зберігаються. Нові37/38pending
мають contract1 і повторно перевіряють NASA після перезапуску.

Пошкоджений або нечитабельний виробничий журнал більше не замінюється
порожнім. API4, ProjectE hotfix і station guards збережені. Оригінальні
optional binaries, повний клієнт, JEI, Survival і TPS ще не перевірені.

Зупиніть гру, розпакуйте пакет окремо й виконайте
`python install_runtime.py "C:\CurseForge\AllInOneAdventure2" --dry-run`.
Після перевірки повторіть без прапорця й повністю перезапустіть обидві сторони.
Інсталятор резервує змінювані файли та старий власний JAR; світи й прогрес
гравців не редагуються.
