# AIA2 Quest & Progression System

Версія **0.4.8-alpha** для Minecraft1.21.1 NeoForge, FTB Quests2101.1.36, KubeJS2101.7.2/Rhino build85. Повний0.5 ще розробляється.

**48 епох,96 виробничих ключів,3280 квестів у139 главах,618 нативних custom-рецептів і390 предметів/моделей/PNG.** Збережено всі3261 попередні quest/task/reward payloads і залежності, крім координат, та615 recipe entries.96legacy ручних цілей залишаються.

Додано18 досліджених Powah-квестів і одну підготовчу EnderIO-ціль. Три Nitro upgrades виготовляються через Create mechanical5×3 зі збереженням native матеріалів і магічно-технічними компонентами.

Вогонь і Fire Water використовують спільний захист Fire Crafting. На епосі19 присядьте й натисніть правою кнопкою з кресалом по **верхній грані** допустимої основи. Після підтвердження запаліть звичайним кліком. Цей виробничий майданчик належить команді основи; незакріплений природний вогонь не виробляє предметів. Старі майданчики після оновлення потрібно закріпити один раз. Заміна основи відкликає власника; згасання вогню на bedrock не відкликає.

Встановлюйте matching kubejs/config/mods через install_runtime.py з --dry-run, із закритою грою. Інсталятор резервує оригінали, зберігає світи й сторонні квести та вимагає matching0.4.8/API4JAR. Повністю перезапустіть клієнт і сервер.

166 Python tests,50 Node tests,5237 Java assertions і90 перевірок мінімального Minecraft у2JVM: PASS. Нові optional handler/model перевірки46 не доводять live EnderIO dispatch. Повний модпак, JEI/UI, Survival іTPS: NOT RUN.
